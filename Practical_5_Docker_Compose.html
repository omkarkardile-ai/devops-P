 2. Check Docker Installation
 Open PowerShell or CMD and run:
   docker --version
   docker compose version
   docker info

 Docker Desktop should be installed and running. If these commands show version details and Docker Engine
 information, continue.

 3. Create the Project Folder
 Create a folder named docker-compose-practical and open it in VS Code.
   mkdir docker-compose-practical
   cd docker-compose-practical
   code .

 Create these three files in the same folder:
   docker-compose-practical/
   ■
   ■■■ Dockerfile
   ■■■ compose.yaml
   ■■■ index.php

 4. Create the PHP Web Application
 Create a file named index.php. The page connects to MySQL using the hostname db, creates a small table, inserts
 one sample record if the table is empty, and displays the stored data.
   <?php
   $host = "db";
   $user = "root";
   $password = "root123";
   $database = "studentdb";

   $conn = null;

   for ($i = 0; $i < 20; $i++) {
       $conn = new mysqli($host, $user, $password, $database);
       if (!$conn->connect_error) {
           break;
       }
       sleep(2);
   }

   if (!$conn || $conn->connect_error) {
       die("Database connection failed.");
   }

   $conn->query("CREATE TABLE IF NOT EXISTS students (

       id INT AUTO_INCREMENT PRIMARY KEY,
       name VARCHAR(100) NOT NULL
   )");

   $result = $conn->query("SELECT COUNT(*) AS total FROM students");
   $row = $result->fetch_assoc();

   if ($row["total"] == 0) {
       $conn->query("INSERT INTO students (name) VALUES ('Demo Student')");
   }

   $result = $conn->query("SELECT id, name FROM students");

   echo "<h1>Docker Compose Practical</h1>";
   echo "<h2>Database connection successful!</h2>";
   echo "<h3>Student Records</h3>";
   echo "<ul>";

   while ($student = $result->fetch_assoc()) {
       echo "<li>" . htmlspecialchars($student["name"]) . "</li>";
   }

   echo "</ul>";
   $conn->close();
   ?>

 Save the file. The connection retry helps the web application wait briefly while MySQL starts.

 5. Create the Dockerfile
 Create a file named exactly Dockerfile (without .txt). It uses PHP with Apache, installs the MySQLi extension and
 copies the web page into Apache's web directory.
   FROM php:8.2-apache

   RUN docker-php-ext-install mysqli

   COPY index.php /var/www/html/index.php

   EXPOSE 80

 6. Create the Docker Compose File
 Create compose.yaml and add the following configuration. It defines the web and db services, port mapping,
 dependency, MySQL environment variables and persistent storage.
   services:
     web:
       build: .
       ports:
          - "8000:80"
       depends_on:
          db:
            condition: service_healthy

     db:
       image: mysql:8.0
       environment:
         MYSQL_ROOT_PASSWORD: root123
         MYSQL_DATABASE: studentdb
       volumes:
         - mysql_data:/var/lib/mysql
       healthcheck:
         test: ["CMD", "mysqladmin", "ping", "-h", "localhost", "-uroot", "-proot123"]
         interval: 5s
         timeout: 5s
         retries: 10

   volumes:
     mysql_data:

 The Compose service name db works as the database hostname inside the Compose network. Do not use localhost as the PHP
 database host.

 7. Build and Start Both Containers
 Make sure the terminal is inside the project folder, where compose.yaml is saved. Run:
   docker compose up -d --build

 Docker downloads the required images, builds the PHP web image and starts both services in the background.

 Check running containers
   docker compose ps

 You should see the web and db services running. The database health status should become healthy after MySQL
 finishes starting.

 8. Verify the Web Application
 Open a browser and visit:
   http://localhost:8000

 Expected result: the page displays Database connection successful! and a sample student record named Demo
 Student. This confirms that the PHP web application connected to MySQL and retrieved data.

 Verify from the terminal
   docker compose exec db mysql -uroot -proot123 -D studentdb -e "SELECT * FROM students;"

 The command should display the student record stored in the MySQL database.

 9. View Logs
 Use these commands to view logs for both services or an individual service:
   docker compose logs
   docker compose logs web
   docker compose logs db
   docker compose logs -f

 Press Ctrl + C to stop following live logs. This does not stop the containers.

 10. Scale Down the Application
 To reduce the web service to one container, run:
   docker compose up -d --scale web=1
   docker compose ps

 This practical's web service uses a fixed host port (8000), so keep one web replica when using this port mapping. The command
 ensures the service is running with one replica.

 11. Stop and Remove Containers and Volumes
 To stop and remove the containers, network and the named database volume, run:
   docker compose down -v

 The -v option removes the named volume mysql_data, so the stored database records are deleted. Without -v, the
 named volume is retained.

 Optional cleanup
   docker compose ps -a
   docker images

 12. Important Commands for Practical

        Purpose                            Command

        Build and start                    docker compose up -d --build

        Check containers                   docker compose ps

        View all logs                      docker compose logs

        Follow logs                        docker compose logs -f

        View web logs                      docker compose logs web

        View database logs                 docker compose logs db

        Scale web to one                   docker compose up -d --scale web=1

        Stop and remove with volumes       docker compose down -v

 Result: A PHP web application and MySQL database were successfully configured and run as a multi-container
 application using Docker Compose.
